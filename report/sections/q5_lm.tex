\subsection{Problem Formulation}
We study probabilistic language modeling on WikiText-2. Given a token sequence $w_1, \ldots, w_N$, the model estimates the next-token distribution and can generate text. We compare a classical trigram model with Kneser-Ney smoothing against neural sequence models (LSTM and a small Transformer). Evaluation uses perplexity and short generated samples.

\subsection{Dataset Description}
We use the WikiText-2 raw dataset with the official train/validation/test splits. Lines that are empty or section headers are removed, text is lowercased, and an \texttt{<eos>} token is appended at line boundaries.

\subsection{Methodology}
\textbf{Trigram Kneser-Ney.} We train a 3-gram model with Kneser-Ney smoothing (discount $D=0.75$). Kneser-Ney discounts observed counts and redistributes probability mass to lower-order n-grams using continuation probabilities, which improves estimates for rare and unseen events compared to add-one or backoff baselines.

\textbf{LSTM language model.} We use a 2-layer LSTM with 200-dim embeddings and hidden size 200, batch size 64, and BPTT length 64. Weight tying is used between input embeddings and output projection. We train for 3 epochs with SGD.

\textbf{Transformer LM (optional).} A small Transformer encoder LM is trained for 2 epochs with batch size 64 and BPTT length 128. This run is intentionally lightweight and mainly for comparison.

\textbf{Perplexity.} We report perplexity defined as
$$
\text{PPL}(W) = P(w_1, w_2, \ldots, w_N)^{-1/N}.
$$
Lower perplexity indicates better predictive performance.

\subsection{Discussion}
N-gram models capture short-range patterns and remain strong baselines on small corpora, but they lack global coherence and struggle with long dependencies. The LSTM should improve coherence with sufficient training, but in this short run it underfits and yields very high perplexity. The Transformer is even more data-hungry and requires more epochs or regularization to stabilize. Perplexity does not always align with perceived text quality, but here the ordering matches the observed fluency: the lowest-PPL trigram output is still more readable than the neural models trained for only a few epochs.
